# ZainKhanPersonalWebsite

Personal Vue portfolio website for Zain Khan, focused on computer architecture, embedded systems, robotics, educational software, and STEM teaching work.

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

This repo includes a GitHub Actions workflow that builds the Vue app and deploys
the `dist` folder to GitHub Pages on every push to `main`.
